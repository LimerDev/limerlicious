# Limerlicious — Theme Description

## Overview

Limerlicious is a dark theme family built around a muted, low-contrast aesthetic with lime-green as its primary accent. The goal is a comfortable coding environment — not harsh, not too colorful — where the key structural elements of code are visually distinct without competing for attention.

Semantic highlighting is enabled across all variants.

---

## Color Philosophy

- **Backgrounds** are neutral dark grays with no color cast.
- **Foreground text** defaults to a light neutral gray (`#c9c9c9`) — readable without being stark white.
- **Lime green** (`#6fcf62`) is the signature accent: cursor, active indicators, badges, selection highlights.
- **Color is earned** — syntax color is reserved for things that matter (types, functions, keywords, strings). Variables and properties are near-white/gray by default.

## Variants

### Limerlicious Dark
The base variant. Medium-dark backgrounds, muted but clear syntax colors. Designed for long sessions.

### Limerlicious Dark Neon
Darker backgrounds with more saturated, vivid syntax colors. Same hue family as Dark but pushed toward neon intensity. For those who want more visual pop.
